## 天梯赛与赛事系统基础功能

“认证球房用华彩天梯周赛模板建赛，按单败淘汰编排”这句话里，**天梯周赛**是办的赛事，**华彩十六球**是比赛项目，**单败淘汰**是赛制。

| 术语 | 项目中的含义 |
|---|---|
| 赛事系统基础功能 | 各类赛事共用的办赛功能，包括配置赛事模板、创建与发布赛事、报名和名单确认、编排赛程、检录、记分、确认名次和归档。 |
| 天梯赛（天梯赛事） | 按档位执行让分规则的赛事。天梯周赛、天梯月赛、天梯季赛、天梯全国赛各自独立办赛，各有报名名单、签表和正式名次。 |
| 天梯对局 | 认证球房开放天梯时段后，两名会员扫同一张球台的台码打球。符合条件的对局用于计算战力；日常对局没有赛事报名、签表和名次。 |

## 赛历、模板和规程

| 术语 | 项目中的含义 |
|---|---|
| 中台协（CBSA） | 中国台球协会。中台协创建官方赛事模板，规定办赛方可以调整哪些设置。 |
| 官方赛历（年度赛历）、官方赛事计划 | 赛历列出官方安排的赛事。计划是其中的一项，例如某个月在北京举办的一站比赛。每项计划至少关联一份模板，建赛人自行决定是否关联这项计划。 |
| 赛事模板（办赛模板） | 一套可重复使用的办赛设置，规定比赛项目、预设组别、各轮打法和哪些字段可以改。关联官方赛历时须从计划里选一份，民间赛事可不选模板、从头填写。官方模板由中台协配置，俱乐部常用模板可重复用于本俱乐部办赛。 |
| 模板版本 | 创建本届赛事时采用的那一版模板。同一模板以后普通改版，已建赛事继续用原先选定的版本。 |
| 预设值（默认值）、可改范围、固定项 | 预设值是选模板后带出来的值，可改范围说明办赛方能怎样调整。例如预设 32 人，允许选 32 或 64 人。如果固定为 32 人，建赛时只能用 32 人。 |
| 竞赛规程（赛事规程） | 写给本届办赛人员和参赛者的比赛规则，说明谁能报、怎么打、怎样晋级和定名次。 |

## 组别、阶段、轮次、场和局

| 术语 | 含义 |
|---|---|
| 组别、预设组别 | 组别是同一赛事中分别报名、分别排名的一群选手，如公开组和女子组。预设组别是模板已经建好的组。使用模板时能否再加组，由模板决定。民间赛事不选模板时自行建组。 |
| 阶段 | 一个组的比赛可以分几段打。例如先打资格赛，选出 16 人，再进入正赛。 |
| 轮次 | 一个阶段里的一轮对阵。例如正赛的 16 进 8、8 进 4、半决赛、决赛。 |
| 场（赛事场次）、局、杆（上手轮次）、实际击球 | 签表上两方的一次对阵是一场。BO5 打成 3 比 1，合计 1 场、4 局。统计杆效时，一杆是选手一次上台连续击球的机会；同一选手上台后连续击球 5 次再换人，记为 1 杆、5 次实际击球。[场次和记分记录的对应关系](概念/场次、对局与局记录.md) |
| 晋级、出线 | 晋级指进入下一轮或下一阶段。出线常指从资格赛或循环小组选出选手，进入下一阶段。 |
| 名次赛 | 专门为分清名次而打的比赛。例如两名半决赛负者再打一场，胜者第三，负者第四。 |

## 每轮的比赛模式和单场局制

| 术语 | 比赛办法 |
|---|---|
| 比赛项目（运动项目） | 指选手打哪种台球，例如华彩十六球、普尔或斯诺克。办赛方选定模板，比赛项目就随之确定。民间赛事不选模板时，办赛方自行填写比赛项目。同一项目可以采用不同的比赛模式。 |
| 轮次赛制 | 每轮要定两件事。**比赛模式**决定这一轮怎么配对、谁能晋级，例如单败淘汰。**单场局制**决定每场双方各要赢几局，有模板时按模板执行官方让局或 BO，民间赛事不选模板时用 BO 平打。 |
| 单败淘汰（单淘） | 输一场就退出该阶段的晋级竞争。32 人全程单败决出冠军，需要打 31 场，名次赛另算。 |
| 双败淘汰、胜部、败部 | 选手从胜部开始，输一场转入败部，再输一场就退出该阶段。双败也可以打到选足出线人数就结束。 |
| 小组循环、循环小组 | 同一个组别的选手还可以再分成几个小组。单循环时，每人和同小组其他选手各打一场。例如公开组分成 A、B 两个循环小组，分别选人出线。 |
| BO（Best of）、抢几 | BO 数写一场最多打几局，“抢几”说先赢几局。**BO3 抢 2，BO5 抢 3，BO7 抢 4，BO9 抢 5。** 一方先达到目标，本场就结束。 |
| 档位、档差 | 档位表示选手的水平，档差是双方相差几档。执行官方让局时，取双方当场开球前扫码时的档位。 |
| 官方让局、平打 | 官方让局按本届模板指定的表确定双方各要赢几局。例如华彩十六球相差 2 档时，高档方要赢 5 局，低档方要赢 3 局。平打时双方条件相同，谁也不用给对方让局或让球。 |
| 单局让球 | 在一局里面给予一方打球上的让步，例如按规程可少打指定的目标球。是否启用、怎样让、在哪几轮让，均由赛事模板规定，办赛方不能自定。无模板时不让球。 |

## 报名人数和可安排人数

| 术语 | 人数的确定方法 |
|---|---|
| 计划参赛人数 | 建赛时办赛方打算接收多少人。名单还没有确定，先用这个数预排。 |
| 人数上限、正式名额 | 该组最多能接收的正式参赛人数。例如上限 32 人，就是最多有 32 个正式名额。 |
| 已确认人数 | 办赛方已经确认进入正式名单的人数。例如上限 32 人，目前确认 20 人，就还有 12 个正式名额。 |
| 候补名额 | 正式名额满后，给选手排队等待递补的位置。候补单独计数，递补并获确认后才占正式名额。 |
| 可安排人数 | 系统按可用时段、球台、所需工作人员和本届打法试排后，能安排的参赛人数。 |
| 最低可安排人数 | 官方模板对办赛条件的最低要求。例如要求能安排 32 人，预排只能安排 24 人，就无法完成建赛。这里核对的是能容纳多少人。 |

## 对阵、签表和赛程

| 术语 | 含义 |
|---|---|
| 对阵 | 一场比赛的双方。名单还没确定时，也可以写成“A 组第一对 B 组第二”。 |
| 签表、签位 | 签表列出各轮谁对谁、出线后往哪里走。签位是其中一个位置，可以先写“上一轮胜者”，等结果出来再填人名。 |
| 抽签、落位 | 抽签是用规程规定的办法决定位置。落位是把选手或晋级来源填到具体签位上。 |
| 种子选手、抽签回避 | 种子选手按规程指定的依据选出，抽签时分散到不同区域。抽签回避则限制哪些人过早相遇，例如同球房选手首轮尽量避开。 |
| 轮空 | 这一轮无需和对手打就可以晋级。例如 10 人用 16 个签位，首轮 6 人轮空、4 人打 2 场。轮空不占球台。 |
| 赛程（赛事赛程）、排台（排桌） | 赛程写明各场的日期、时间和球台。排台就是把某场对阵安排到一张具体可用的球台上。 |
| 预排（试排）、正式对阵 | 预排用计划人数画出空签表，估算球台、人手和时段能否排下所有比赛。名单确认后，才把具体选手排入正式对阵。[预排计算方法](赛程预排与计算公式.md) |
| 发布赛事、发布赛程 | 发布赛事后，选手能在规定时间报名。发布正式赛程后，选手能查在哪一轮、什么时间、哪张球台打，对手是谁或由哪一场产生。[发布后的办赛流程](赛事发布后怎么走.md) |

## 预排结果的含义

| 术语 | 数值的含义 |
|---|---|
| 批数 | 同一轮的比赛要分几拨打。例如首轮 16 场、8 张球台都可用，至少要分 2 批。两批都属于首轮。 |
| 工作人员 | 办赛方指定的现场人员，可安排到具体场次负责记分等工作。排赛程时要看本人在哪些时段能到场。 |
| [台费](台费.md) | 使用球台的费用。建赛时写明一场打完后由谁承担，与报名费分开说明。 |
| 台分钟 | 1 张球台使用 1 分钟，就是 1 台分钟。两张台同时开打 30 分钟，合计 60 台分钟，钟表上过去了 30 分钟。 |
| 换场时间、选手休息时间 | 换场是球台从上一场打完到下一场能开打的间隔。休息是同一选手两场之间要留的时间。两段可以重叠，台和人都就绪才能开打。 |
| 时间冲突 | 同一选手一届只能报一个组。组内连续两场须留足休息时间。不同组可以共用球台、人手，同一时间一张台或一名工作人员只能安排给一场。 |
| 可用时段、预计完赛时间 | 可用时段由办赛方填写，例如球台 18:00 收台。预计完赛时间是系统排完所有场次后算出的最后一场结束时间，例如 17:40。 |

## 从报名到领积分，几个相近的词

| 容易混的词 | 放在一届比赛里看 |
|---|---|
| 待定（预备名单）、候补、确认（正式名单） | 待定是已申请、待办赛方确认。候补是正式名额已满，选手在等空位。经确认进入正式名单才占正式名额。 |
| 待定对手、轮空、弃权 | “资格赛第一名”是有来源、还没定姓名的对手，必须等前场结果。轮空是按签表直接晋级。弃权是已有参赛人按规程退出或被记弃权，要留下处置记录。 |
| 检录、开球 | 检录核对到场选手和本场对阵。开球前扫码取实际档位，按模板确定让局、让球。 |
| 比分、名次、赛事积分 | 3 比 1 是本场比分，冠军是本组名次。若该组终评 2 级，按默认积分表冠军得 600 分。球员榜汇总符合条件的多站积分。 |
| 战力（ZL）、天梯档位（D 档）、考级 | 战力来自有效对局取样，档位是系统据此评定的水平分档。赛事按一场对阵取样，日常天梯按一次扫码对局取样，均需满足有效记录条件。符合映射条件的协会技能考级也可用于定档。球员赛事积分单独计算。 |
| 赛事认证标识、组别计分等级 | 整届获金、银或铜标。积分查本组终评等级，一届赛事的不同组可以不同。 |
| HY、JF、PX、MH（外部系统） | 分别指会员系统、第三方记分系统、培训考级系统和对外门户。参赛者身份、场上记分、考级记录、公开成绩各有来源。 |

## 办赛沟通与系统对接用语

以下词从旧字典选入，供读历史资料、接口和代码时对照。括号中的旧编号可用于追溯用词。交付阶段、权限和计算条件查 v2.0 对应专题。

| 用词 | 在项目中怎么用 |
|---|---|
| 开启天梯（A07） | 球房按球台、日期和时段开放日常天梯入口；创建一届周赛还要单独建赛、开报名、编排。 |
| 赛事日程（A18） | 指本届报名、报到、抽签、正赛等环节的日期安排。精确到某场对阵的时间和球台时称“赛程”。 |
| 系列赛、分站赛事（A13–A14） | 系列可包含多站；一站可以是独立的一届赛事。跨站资格与本届资格赛出线分别处理。 |
| 制胜球（A03） | 华彩规则中决定该局胜负的目标球，具体击打条件依该项竞赛规则。 |
| 模板快照（B16） | 记录本届采用的模板内容，便于普通改版后还原当时的设置。[模板与本届赛事](赛事模板.md) |
| 主办、承办、协办、冠名（C04–C07） | 分别表示发起并总体组织、负责具体承办、协助执行、取得冠名展示的关系。本届主办单位按实际发起和组织安排确认；仅选用官方模板不能认定为中台协主办。人员授权另查本届指派。[办赛角色与权限](办赛角色与权限.md) |
| 组织授权、本届指派（C17–C19） | 前者核对账号可以代表哪个单位，后者核对在本届、该组或该场被分配的具体工作。首位经办人的授权归属见[待确认事项](赛事待确认事项.md)。 |
| 桌码、设备绑定（G09–G10） | 桌码用于识别球台。绑定表示设备与球台的对应关系；能否采到完整比赛数据要核对连接和实际记录。 |
| 设备能力档、无设备球台（G11、G13） | JF 的 A 档可提供原子过程数据，B 档提供逐次击球摘要，C 档提供比分与逐局结果。无设备球台没有接入 JF。当前反馈将 C 档现场记分作娱乐处理，需求保留计战力开关。[有效记录的条件](<赛事档位、战力与让分.md#计入战力的有效记录>) |
| 对局会话（M07）、采集会话（M08）、登录会话（M09） | 依次用于关联平台侧参与人及局记录、组织厂商采集、管理账号登录状态。厂商与平台 ID 的对应关系按协议核对。一次重连是否新建采集记录，与原场次和局数分别判断。[场次与对局记录](概念/场次、对局与局记录.md) |
| 设备事实、引擎判定、人工裁决（M11） | 分别回答设备观测到了什么、程序依规则判了什么、有权人员最后怎样处理争议。记录来源有助于复核。[现场续赛与改分](现场续赛、申诉与改分.md) |
| 补传、补拉、幂等（M14–M15） | 提供方重新发送叫补传，接收方主动取回叫补拉。重传同一局只产生一次有效业务结果，是幂等要求。比分有差异时核对原场、局次和修订依据。 |
| 修订、作废、冲突（M16） | 修订更正既有记录，作废撤销其有效性，冲突指多份记录不能同时成立。正式成绩更正的权限及步骤见[锁定后的改分](<现场续赛、申诉与改分.md#正式成绩锁定后的改分权限>)。 |
| 录像索引（M18） | 指向同场录像及对应局次、时间点，可用于复核。是否满足战力取样条件还要核对采集字段。 |
| 主身份、会员号、手机号（O07） | 依次用于跨业务关联同一人、识别会员体系编号、联系或登录。对接时分别核对字段及映射关系。[会员身份与参赛资料](会员身份与参赛资料.md) |
| 实名核验、照片互认、人脸核验（N12） | 分别指核对实名资料、由人核对对手照片、通过算法比对人脸。描述已具备的能力时写清实际采用哪一种。 |
| 模块简称 SS、MS、TT、RF、PC、PT（M01–M02） | 在历史接口和代码中依次指赛事、对局会话、华彩天梯、裁判、个人挑战、积分与成长。讨论业务用中文全称，所处阶段见[赛事业务范围](赛事业务范围.md)。 |
| PJG、GX、SL、SC（O01–O04） | 历史公式分别指平均获胜杆数、杆效项、胜率项、累计胜局项。默认参数、零胜局和取样处理统一查[战力取样与定档](<赛事档位、战力与让分.md#从战力取样到确定档位>)。 |
| 模拟联调、真实设备实测、灰度、验收（N07–N10） | 写项目状态时说明验证的是模拟交互、现场设备、限定业务范围内运行，还是按约定条件验收；标出相应环境和证据。 |
