# 赛事模板

中台协创建和配置官方模板，可以直接启用，无需审核。比如给华彩十六球赛事建一份只带公开组的模板，可以这样设置。

| 设置 | 模板设置 | 建赛时的结果 |
|---|---|---|
| 预设组别 | 公开组，禁止新增组别 | 本届只带出公开组。 |
| 人数上限 | 固定为 32 人 | 正式参赛人数上限为 32 人。 |
| 候补人数 | 允许修改 | 办赛方自行填写候补名额。 |
| 32 进 16 | 单败淘汰，BO5 | 每场先赢 3 局的一方晋级。 |

## 模板规定预设值和可修改范围

中台协先给模板命名、定下比赛项目，再设组别、阶段和轮次，最后逐项说明办赛方能改什么。**模板可以同时规定「带出什么值」和「能改到什么程度」**。例如人数上限可以先带出 32 人，同时允许办赛方在 32、64 人中选一个。预览时应能看到预设值、允许的范围和固定原因。

官方模板用于统一办赛要求。俱乐部若复用以往办赛设置，可用常用模板带入人数、收费和打法。民间赛事也可以不选模板，由办赛方重新填写比赛项目、组别、人数、费用和各轮打法。此时各轮采用 BO 平打。俱乐部常用模板是复用设置的一种方案，官方赛事计划可用哪些模板由中台协配置。

## 模板字段清单

### 一、模板标识和使用条件

| 字段 | 填写内容 |
|---|---|
| 模板编号 | 系统识别这份模板用的编号。 |
| 模板名称 | 办赛方建赛时按这个名称选模板。赛事资料中的“赛事模板”显示所选模板的名称。 |
| 模板类型 | 说明这份模板是中台协官方模板，还是俱乐部常用模板。 |
| 比赛项目 | 在模板中设定，例如华彩十六球。选用这份模板的赛事都使用该项目，办赛方建赛时不能修改。 |
| 使用条件 | 哪些办赛单位能用，例如需具备相应认证资格。 |
| 模板版本 | 本届赛事采用哪一版。 |
| 启用状态 | 新建赛事时能否选择这份模板。 |
| 各项预设值 | 使用模板时带出的组别、比赛规则和估时参数。 |
| 各字段的修改规则 | 办赛方使用模板时，比赛项目、让局和让球规则都随模板执行。其他字段分别设置能否修改、允许选什么值、上下限是否包含端点。必要时说明固定原因。 |

一项官方赛事计划至少关联一个赛事模板。办赛方选择关联该计划时，使用计划下适用的模板。使用模板建赛时记录所用的版本，之后按该版本执行。普通模板升级后，新建赛事使用适用的新版本。[计划和模板的用途](<决策记录/2026-11-23 办赛规则为什么这样定.md#办赛方自行选择是否关联官方计划>)

### 二、整届赛事的安排

| 字段 | 填写内容 |
|---|---|
| 开赛时间 | 模板有开赛时间要求时，本届须遵守。办赛方建赛时确认实际开赛时间。关联官方计划时，日期还要落在计划允许的时段内。 |
| 可用球台数量 | 模板可规定球台数量要求，办赛方在建赛时填实际可用数量。 |
| 台费承担方式 | 规定免台费、双方平摊、胜方付或负方付，也可以限定办赛方可选的方式。[台费](台费.md) |

| 模板中的其他比赛设置 | 建赛用途 |
|---|---|
| 赛事初始等级 | 登记或预评级用。发积分时还要查本组终评等级。 |
| 是否计战力、是否可用作测试赛 | 允许计战力后，还要逐场核对采集数据。赛事积分另查认证资格和计分设置。测试赛的数据单列，不进正式积分榜。 |
| 局间动态让球、让分规则版本 | 由官方模板规定是否按上一局结果调整下一局让球。办赛方沿用生效版本。 |
| 报名时段要求、报名资料、互认照片、承诺说明链接 | 模板规定报名条件和所需材料，办赛方建赛时确认本届实际报名起止时间。 |

天梯周赛、天梯月赛、天梯季赛和天梯全国赛的让球固定开启。让局由官方模板规定，默认开启，办赛方按模板执行。选手尚未定档时平打。王中王等按规程平打的赛事使用相应模板。

上述字段见产品需求 §1.4.1 · 阶段一模板内容。第二阶段 FR-SS-18 还列了报到及抽签安排、推荐与外卡名额、报名资格和附件。具体赛事只启用适用的条款。

### 三、预设组别和报名条件

- **预设组别**。选择建赛时自动带出的组，例如只带出公开组。
- **是否允许新增组别**。选择只使用预设组别，或允许办赛方新增。允许新增时，新组的赛程按模板规定的范围设置，模板未限制的部分由办赛方设置。

| 每组的字段 | 填写内容 |
|---|---|
| 组别名称 | 如公开组、女子组。 |
| 年龄要求 | 报名年龄或年龄范围。 |
| 性别要求 | 本组是否限制报名者的性别。 |
| 档位要求 | 可报名的档位或档位范围。 |
| 人数上限 | 最多接收多少名正式参赛者。 |
| 建赛所需的最低可安排人数 | 模板若要求至少安排多少人，建赛时用系统预排结果核对。 |
| 固定轮次规则的人数范围 | 填本组适用的人数范围、是否包含上下限，以及命中后哪些轮次按模板执行。 |
| 候补人数 | 最多接收多少名候补。 |
| 报名费 | 本组每人交多少，免费或减免适用于哪些人。 |

**抽签和让球**

| 每组的字段 | 填写内容 |
|---|---|
| 是否设置种子 | 抽签时是否设种子选手。 |
| 种子人数 | 如果设置种子，设几名。 |
| 种子排序依据 | 如果设置种子，按哪项记录排，例如官方积分。 |
| 抽签回避规则 | 首轮是否回避同球房或同单位。种子按规程分散到不同半区或分区。 |
| 轮空分配 | 是否优先把首轮轮空分给种子。轮空者自动进入下一轮。 |
| 是否启用让球 | 由模板规定本组是否执行单局让球。办赛方建赛时不能自行开关。 |
| 让球办法和适用轮次 | 模板中写明让球办法、上限和适用轮次，建赛时直接沿用。华彩十六球按适用的官方规程。 |

**名次赛**

下面三项各设一个开关。

- 是否决出第 3、4 名
- 是否决出第 5、6 名
- 是否决出第 7、8 名

### 四、各阶段的参赛来源和出线规则

例如先打资格赛，再让出线选手进入正赛。

| 字段 | 填写内容 |
|---|---|
| 阶段名称 | 如资格赛、正赛。 |
| 阶段顺序 | 哪个阶段先打。 |
| 参赛来源 | 哪些人能进这个阶段，如本组报名者或上一阶段出线者。 |
| 参赛人数 | 这一阶段有多少人参加。 |
| 晋级人数 | 这一阶段有多少人出线。 |
| 晋级去向 | 出线选手进入哪个阶段。 |
| 循环小组数 | 采用小组循环时，分几个小组。 |
| 每组出线人数 | 采用小组循环时，每个循环小组出线几人。 |
| 胜部、败部出线名额 | 双败选拔若分别取胜部和败部出线者，填写各自名额，两者之和等于本阶段晋级人数。 |
| 出线顺序和签位 | 循环组先比积分，再比相互胜负。三人相互胜负仍相同时再比胜负场，剩余并列按本届规程处理。写清出线者进入下一阶段哪个签位。 |

### 五、每轮的比赛模式和局制

每轮先选**比赛模式**，再选**单场局制**。同一轮允许选择不同比赛模式时，模板可分别指定各模式适用的局制。128 进 64、64 进 32、32 进 16、16 进 8 和 8 强都可分别设置。同组同阶段内，后续轮次可沿用上一轮已生效的设置，单独改了一轮就从该轮起按新设置执行。进入新阶段，先确定新阶段首轮的规则。

| 字段 | 填写内容 |
|---|---|
| 轮次名称 | 如 128 进 64、64 进 32、32 进 16、16 进 8、8 强。 |
| 轮次顺序 | 各轮按什么顺序打。 |
| 比赛模式 | 单败淘汰、双败淘汰、小组循环三选一。决定对阵和晋级。 |
| 单场局制 | 模板为本轮规定官方让局或 BO。采用官方让局时，办赛方按模板指定的表执行，不能改成自定的胜局数。 |
| 胜部、败部与决赛的局制 | 分开设置时，分别写明各轮采用的官方让局或 BO。 |
| BO 局数 | 选了 BO 时，填写 BO3、BO5、BO7 或 BO9。 |
| 预计单场用时 | 写明本轮预计打几分钟、是否含换场。也可给出单局平均分钟，结合本轮局制估算。 |
| 换场和休息时间 | 球台在两场之间要留几分钟，同一名选手连打时至少休息多久。两项分别计时。 |

| BO 局制 | 胜局条件 |
|---|---|
| BO3 | 最多打 3 局，先赢 2 局。 |
| BO5 | 最多打 5 局，先赢 3 局。 |
| BO7 | 最多打 7 局，先赢 4 局。 |
| BO9 | 最多打 9 局，先赢 5 局。 |

**其他办赛方式留作后续参考。** 瑞士轮按成绩配对。积分排名赛按多轮累计积分排名。麦克马洪制带初始分配对。分档积分赛按档位安排抽签和对手。自定义赛程由办赛方指定对阵。第一阶段使用单败和小组循环，可分阶段衔接。双败列在第二阶段。产品需求 §1.4.4、§2.4.3 · 阶段一送审稿 §13名次赛属于各组自己的设置。

### 官方让局按双方档位确定胜局数

模板规定本轮采用官方让局时，开球前按双方当场扫码时的档位查表。双方确认各自要赢几局，整场按这个目标打。若模板同时规定了单局让球，另按该模板的让球办法执行。下表是附件 4《中国台球协会数字化系统建设方案》第 4.5.2 节的华彩十六球让局表。

| 档差 | 高档方所需胜局数 | 低档方所需胜局数 |
|---:|---:|---:|
| 0 | 5 | 5 |
| 1 | 5 | 4 |
| 2 | 5 | 3 |
| 3–4 | 5 | 2 |
| 5 | 6 | 2 |
| 6–7 | 7 | 2 |
| 8 及以上 | 8 | 2 |

华彩十六球按这张表执行官方让局。现金或代金券都算奖金，只有实物或证书时按无奖金处理。对模板已规定按有奖赛事规则执行的比赛，档差超过 4 档时默认按差 4 档查表。建赛时填写的奖金说明只供选手阅读，让局和让球按模板执行。平打使用所选 BO 局制。中台协 Q-66 · 官方让局表 · 中台协 Q-142 · 哪些算奖金 · 附件 4 §4.5

## 模板字段的修改权限

赛事、组别、阶段和轮次下的字段，可以分别设置模板值和填写方式。比如人数上限和候补人数分别设置，一项固定、另一项可改。

| 模板设置 | 填写与校验 |
|---|---|
| 固定 | 使用模板指定的值。提交时如果修改了，系统拒绝保存并指出哪个字段是固定的。 |
| 限定范围 | 例如人数上限只能选 32 或 64。可以规定上下限或允许选择的值，超出范围时拒绝保存。 |
| 开放填写 | 按本届情况填写。系统检查必填项、日期先后等字段要求。 |
| 关闭可选项目 | 例如不打第 3、4 名比赛。这项无需继续填写，保存为关闭。 |

**人数限制按组判断。** 模板可指定在哪个人数范围固定哪些轮次，以及边界是否算在内。办赛方能改的项目仍看各字段的设置。例：模板要求公开组至少能安排 32 人，建赛时系统按本届时段、球台和打法预排。评估只能安排 24 人，本届就不能完成建赛。报名上限和候补人数仍各有自己的修改规则。

模板未固定首轮的比赛模式和单场局制时，办赛方必须在创建赛事的「赛事资源」中明确选择，系统不自动选 BO。

## 办赛方的组别操作权限

| 操作 | 允许操作的条件 |
|---|---|
| 查看 | 有查看权限即可查看组名、参赛条件、人数上限和候补人数。 |
| 新增 | 模板允许新增、办赛方有编辑权限、赛事处于可编辑状态时可以新增。 |
| 编辑 | 每个字段分别检查。例如可以改人数上限时，候补人数仍按它自己的设置处理。 |
| 复制后新增 | 从已有组复制报名和赛制设置，也属于新增。检查新增权限，按新组规则核对字段，单独确定人数、报名费和开赛时段。 |
| 删除 | 只使用预设组别时，保留全部预设组。允许删除时，赛事至少保留一个参赛组别。 |
| 替换 | 分别检查能否删除旧组、能否新增新组。任一操作不允许时，整次修改不保存。 |

使用模板的赛事，在创建和修改时都按所选的模板版本检查。办赛方提交自定义让局或让球规则时，系统拒绝保存。不选模板的民间赛事也不能添加这两类规则。模板要求只使用公开组时，新增女子组、删除公开组或用其他组替换公开组的操作都会被拒绝。

### 有些条款只在采用时填写

以下是竞赛规程里可能用到的项目。模板可按需要收录，具体数值和适用对象由本届规程确定。

| 条款 | 要写清的内容 |
|---|---|
| 收费和奖励 | 按需说明二次报名收费、退费条件、热身台费。办赛方在建赛时用一段文字告知选手本届是否设有奖金。 |
| 比赛细则 | 开球权、犯规和弃权怎样判，出杆是否限时、限多少秒，迟到多久如何处理。 |
| 排程要求 | 组别开赛时间、专用球台或人员要求。实际场馆、可用台号、值班时段在本届建赛时填写。 |

本届开赛后，比赛模式和局制锁定，仍可调整比赛时间。改动时间要复查球台、人员和其他组的安排。
