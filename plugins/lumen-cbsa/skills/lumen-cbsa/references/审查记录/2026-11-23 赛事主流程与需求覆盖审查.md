# v2.0 对赛事主流程的覆盖情况

**v2.0 以天梯赛为主线，覆盖从建赛到归档的赛事系统基础功能。** 认证球房办天梯周赛，要选官方模板、试排球台和时段、发布报名、确认名单和签表。到了球台，双方按扫码时的档位确认本场胜局目标和首局让球。打完后系统推进签表，办赛方确认名次。下面用这条路径核对文档覆盖，系统交付后再实测。产品需求 v2.1 · 典型场景

**整套一期的交付范围仍需与最新送审稿对齐。** 今天在项目文档库里找到《阶段一需求文档·赛事全流程 v3.9》。它把自然年度赛历、登记承办单位列入阶段一，把双败、赛事积分结算和自动积分榜列入阶段二。产品需求 v2.1、知识库和这份送审稿在部分安排上仍有差别。判断能否跑通第一场比赛，先看能否把正式名次交到选手手上。系统实现和上线情况由后续实测验证。阶段一送审稿 §9、§13 · 产品需求 v2.1 §0.3

## 从计划到归档，每一步都有办理结果

| 环节 | 谁来办，完成后留下什么 | v2.0 的依据与结论 |
|---|---|---|
| 1. 定计划、选模板 | 协会定拟办时间、适用模板和承办安排。办赛方建立本届赛事，确定比赛项目与采用的规则版本。 | [年度赛历与赛事计划](../年度赛历与赛事计划.md)和[赛事模板](../赛事模板.md)已分清计划、模板与本届赛事。每项计划可关联几份模板，见下文的版本差异。 |
| 2. 定人数、试排 | 办赛方在同一阶段定场馆、开赛时间、各时段比赛台和工作人员、每组人数、打法。系统把所有组放在一起排，给出容量及预计完赛时间。 | [创建赛事](../创建赛事.md)和[预排公式](../赛程预排与计算公式.md)能指导填写和计算。例如模板要求至少能安排 32 人，试排只能安排 24 人，本届只能存草稿。 |
| 3. 发布赛事、收报名 | 办赛方公布组别、条件、起止时间和费用说明。认证球房办天梯周赛免审，市台协办天梯月赛报省台协审核。选手按条件提交，收费由办赛方线下核对。 | [创建赛事](<../创建赛事.md#第三步　确认报名规则并发布>)已分别说明启用模板、发布一届赛事、开放报名。奖金按项目确认只展示文字。 |
| 4. 确认名单、发布赛程 | 系统检查报名资格，办赛方确认后占正式名额。编排人员用确认名单生成各组签表，安排场次、时间与台号，再发布正式赛程。 | [会员身份与参赛资料](../会员身份与参赛资料.md)已补实名和参赛状态检查。[报名、名单与签位](../报名、名单与签位.md)已说明谁能入签、怎么排种子、资格赛出线者占哪个位置。 |
| 5. 检录、逐局记分、晋级 | 双方核对身份和本场胜局目标。系统累计每局胜负，达到目标就结束本场，淘汰赛胜者进入下一签。 | [赛事发布后的办理流程](../赛事发布后怎么走.md)已补自动记分、工作人员录分及正式赛果进入签表的过程。华彩十六球的胜局判定可对照协会竞赛规则。 |
| 6. 确认名次、公布成绩、归档 | 裁判长或赛事负责人确认本组正式名次。选手查看公示的本组结果。整届各组办理完毕后归档，办赛方可导出最终名次表。 | [赛事发布后的办理流程](../赛事发布后怎么走.md)写明本组和整届的区别。[民间赛事认证与积分](../民间赛事认证与积分.md)另说明启用积分后哪些赛事可以发分、何时发。 |

协会要求一个会员一届只报一组，报名资格看申请时的档位，开球让分取当场扫码档位。商务与协会均提到现场人工记录和系统记录的核对。核查时分别追到了报名、检录和记分专题，以免把三个时点当成同一个字段。中台协 Q-139 · 商务 Q-49 · 中台协 Q-49

## 用天梯周赛检查办赛流程

1. **建赛和预排。** 认证球房选择官方的“华彩天梯周赛”模板，填写比赛日期、记分台可用时段、现场人手和报名上限。系统按本届单败签表试排，给出可安排人数和预计完赛时间。符合模板要求后，球房发布报名。
2. **报名和编排。** 球房核对报名资格并确认名单，用确认名单排出对阵、开球时间和台号，再发布赛程。选手从小程序查自己的场次。
3. **检录、让分和晋级。** 以其中一场半决赛为例。甲、乙检录并互认身份，开球前扫码时甲为 D5、乙为 D3。按本例模板的官方让局表，甲需赢 5 局，乙需赢 3 局。首局按低档方所在档组和两人档差查让球表，乙受让“前一”，即分清花色后把自己的一颗目标球拿起放进袋。系统逐局累计比分。若甲已赢 4 局，乙先赢满 3 局，本场由乙获胜，签表把乙排入决赛。官方让局表与首局让球表
4. **确认名次和归档。** 决赛按两名决赛选手当场扫码的档位确认各自胜局目标。比赛打完，负责人核对并公布名次，选手能查到本届成绩。全部组别办理完毕后整届归档。符合条件的有效场次用于计算战力；赛事积分按对应交付阶段和计分资格办理。产品需求 v2.1 · 天梯赛的产出 · 阶段一送审稿 §9、§13

**赛事系统基础功能也适用于锦标赛。** 2027 全国华彩台球锦标赛的拟办窗口为 9–12 月，分男、女两组。场馆条件列了 16 张比赛台（含 1 张主赛台）和 8 张练习台。落地时要在窗口内定实际日期，按两组共用的比赛台试排。把场馆里所有 24 张台都用于计算比赛容量，会多收人。这条实例检验了“计划月份、本届日期、比赛台数量”三个字段各自的用途。2027 年赛事活动资源推介册，第 20–21 页

## 送审稿与已确认需求有四处要对齐

| 涉及的决定 | 项目已采用的口径 | 送审稿的写法及处理 |
|---|---|---|
| 计划、模板与民间建赛 | 每项官方计划至少关联一份模板。办赛方选了计划，再从关联模板中选。民间赛事可选模板，也可不选并自行填项目。 | §3.4 天梯类计划须指定一份官方模板及版本；§4.4 提供“通用空白”模板。评审时用“一项计划提供 A、B 两模板”和“民间赛事从空白建赛”对照两稿。 |
| 首轮打法与锁定 | 模板锁定的沿用；开放的首轮模式、局制由办赛方在资源阶段填齐。开赛后比赛模式与局制锁定，比赛时间可调整。 | §4.5 允许从本轮、本阶段、本届逐层取值，按已开打的轮次锁定。要统一首轮是否允许继承、何时锁住后续轮次。 |
| 奖金 | 一期由办赛方填奖金说明，原文展示给选手。让球和让局跟随模板。 | §13.1 把分档奖金计算列入阶段一。附件 4 提供了协会算法；本轮已明确一期只展示文字。应把送审稿和交付清单对齐到这个范围。 |
| 第一阶段办到哪里 | v2.1 已把赛事积分放在第二阶段。知识库原先把年度赛历整体放在第二阶段，且在建赛指南中列出双败，读者容易把全期能力当作首批能力。 | v3.9 §13.1–13.2 列出首批自然年度赛历和承办登记、单败及循环等编排，双败与赛事积分在第二阶段。阶段一用正式名次和归档检验主流程。计分启用后，符合条件且无申诉的赛事按已确认规则立即发分并更新榜单。 |

以上四项影响正常办赛，适合在对齐需求时一次核清。v3.9 明示为送协会评审稿，其中的阶段划分按送审状态引用。首批模板具体参数也以协会最终提供的版本为准。阶段一送审稿 §3–4、§13–14 · [项目办赛决策](<../决策记录/2026-11-23 办赛规则为什么这样定.md>)
