## 办赛流程

第一次接触项目，可以先看认证球房办一届[天梯周赛的完整实例](<审查记录/2026-11-23 赛事主流程与需求覆盖审查.md#用天梯周赛检查办赛流程>)。实际办赛时，按当前环节查下表。

| 环节 | 办理事项 | 文档 |
|---|---|---|
| 确定计划与模板 | 关联官方计划时，从计划关联的模板里选。核对模板预设的组别、人数、各轮打法和可修改的字段。 | [年度赛历与赛事计划](<年度赛历与赛事计划.md>) · [赛事模板字段清单](<赛事模板.md#模板字段清单>) · [组别操作权限](<赛事模板.md#办赛方的组别操作权限>) |
| 建赛与预排 | 先建草稿。第二步把球台、时段、人手、各组人数和打法放在一起试排，算出能收多少人、预计几点打完。第三步确认报名规则并发布。 | [创建赛事](<创建赛事.md#创建赛事分三步，第二步完成资源填写和赛程预排>) · [赛程预排与计算公式](<赛程预排与计算公式.md>) |
| 报名与排签 | 确认正式名单和候补，按规程排种子、抽签，为资格赛出线者预留签位。 | [报名、名单与签位](<报名、名单与签位.md>) |
| 现场办赛与归档 | 发布签表和逐场赛程。工作人员检录，设备或指定人员逐局记分。每场结束后推进签表，各组打完后公布名次，最后整届归档。 | [赛事发布后的办理流程](<赛事发布后怎么走.md>) · [现场派台与球台占用](<赛事发布后怎么走.md#现场派台与球台占用>) |

## 专项规则

| 专项 | 可查内容 |
|---|---|
| [办赛角色与权限](<办赛角色与权限.md>) | 协会、球房和承办单位各能办哪些赛事，办赛方如何指派人员确认报名、编排、检录和记分。 |
| [会员身份与参赛资料](<会员身份与参赛资料.md>) | 协会会员与参赛玩家的身份、会员报名开关、年龄核验和监护人代办。 |
| [台费](<台费.md>) · [奖金说明](<现场续赛、申诉与改分.md#一期奖金仅作文字说明>) | 正式比赛台费由谁承担、热身是否另收费。一期奖金由办赛方填写文字说明，供参赛人查看。 |
| [赛事档位、战力与让分](<赛事档位、战力与让分.md>) | 报名资格取报名时的档位，让局和让球取开球扫码时的档位。打完后，符合条件的对局用于计算战力。 |
| [场次、对局与局记录](<概念/场次、对局与局记录.md>) | 把签表上的一场比赛、设备记录的对局和每一局的胜负对应起来。 |
| [现场续赛、申诉与改分](<现场续赛、申诉与改分.md>) | 换台后沿用原场比分。发生申诉时冻结本届结算，正式成绩需要更正时查申请、执行权限和改分记录。 |
| [民间赛事认证与积分](<民间赛事认证与积分.md>) | 查整届认证标识、各组评级和计分资格。符合条件的赛事按组别终评等级和选手最终名次计算积分、更新榜单。 |
