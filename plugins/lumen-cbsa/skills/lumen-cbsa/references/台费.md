# 台费

台费是使用球台的费用。办赛方建赛时写明谁承担正式比赛台费。赛前热身另有收费办法的，也要告诉选手。

## 本届规程确定台费承担方

假设某场按场馆标准用台共 60 元，甲胜、乙负。60 元只是举例。

| 本届规定 | 甲（胜方） | 乙（负方） |
|---|---:|---:|
| 免台费 | 0 元 | 0 元 |
| 双方平摊（AA） | 30 元 | 30 元 |
| 胜方付 | 60 元 | 0 元 |
| 负方付 | 0 元 | 60 元 |

使用赛事模板时，台费方式已经固定的直接沿用，允许选择的就在规定范围内选。民间赛事不选模板时，由办赛方确定本届采用哪一种。

## 报名时公布台费和热身收费

- **报名费是否已含比赛台费。** 已含就写“报名费已含正式比赛台费，场后无需另付”。如果另收，就写明由谁承担，金额按本届公布的场馆收费标准计算。
- **热身是否另收费。** 正式比赛和练球可以采用不同收费办法。例如规程可以写“正式比赛双方平摊台费，赛前热身免费，其他时段自行练球按场馆标准收费”。
