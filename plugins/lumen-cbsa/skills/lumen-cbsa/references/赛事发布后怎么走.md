# 赛事发布后的办理流程

赛事开放报名后，办赛方先定正式名单，再发布签表和逐场赛程。比赛按场推进，名次按组确认，最后整届归档。

| 办理环节 | 办理事项 | 办理结果 |
|---|---|---|
| 开放报名 | 按已公布的时间、组别和条件收申请。收费时展示收款说明，办赛方在线下核款，选手的报名由经办人确认。 | 每组各有一份确认名单，候补另列。 |
| 排正式赛程 | 按确认名单和本届种子、回避办法落签。资格赛未结束时，为“资格赛出线者”留签位。结合实际可用球台、人手和选手休息安排预计开球时间。 | 发布签表和逐场赛程。选手可在小程序、公开站或现场大屏查到对手或晋级来源、预计开球时间和计划台号。 |
| 现场派台 | 确认球台空出后，系统推荐能打的场次。工作人员确认派台并通知选手到台。 | [本场预留的球台](#现场派台与球台占用)。 |
| 检录、开球 | 工作人员核对到场选手、对阵和球台，双方互认对手。身份有异议时先挂起该场，核验通过再开球。扫码取得当场档位，按本轮生效的局制确认双方各要赢几局。 | 这场比赛的实际选手、开球时间、台号、胜局目标和记分记录。 |
| 逐局记分、推进下一场 | 每打完一局，记下胜方，场比分随之更新。采用设备判分时由系统累计；采用人工记分时，由办赛方指定的工作人员录入。先达到本场胜局目标的一方获胜。 | 单败胜者自动进入下一签。循环赛按本组规则更新小组积分和排名；资格赛出线者填入对应正赛签位。 |
| 确认各组名次 | 本组和所需名次赛打完后，裁判长或赛事负责人核对结果，处理完本组复核项，按规程确认各名次及并列名次。 | 公布已确认组的名次表和签表。选手能查自己的正式成绩，办赛方可导出 PDF 或 Excel 名次表。 |
| 整届归档 | 各组结果齐全、复核项处理完，由有权人员归档。 | 本届签表、正式成绩和赛事报告。 |

## 现场派台与球台占用

一期要能按台号查到这张球台此刻留给哪一场、正在打什么，也能按时间回查当天的用台记录。**预排给出预计时间。工作人员确认派台时，球台开始为该场预留。双方到台确认开球时，这场比赛才开始实际用台。** 同一张台同一时间只能有一项预留或正在进行的用台记录。

例如，3 号台原定 14:00 打天梯周赛 M9。M9 的对手是 M1 和 M2 的胜者。这两场赛果确定、选手满足本届休息要求后，M9 就可以候场，其余首轮场次可以继续打。若球台提前空出、双方也已就位，经确认即可提前开球。

| 现场动作 | 查 3 号台时看到的状态 |
|---|---|
| 14:00 上一场还在打，14:08 才打完并释放球台 | 14:08 前仍由上一场使用。释放后球台空闲，系统向工作人员推荐 M9。工作人员可以确认，也可以换一场。 |
| 14:09 工作人员确认派台并叫号，只有一位选手到台 | **已为 M9 预留，待开球。** 另一位选手到台前，球台继续留给 M9，不能再派给其他场次或开给客人。 |
| 14:14 双方就位并确认开球，14:48 完场释放 | **天梯赛进行中 · M9。** 本场实际用台 34 分钟。14:49 查这张台，状态是空闲。 |
| 14:50 球房给客人开台 | **娱乐用台中。** 14:51 查这张台，能确认客人正在用台。球房确认结束用台后，球台恢复空闲。在本届可用时段内，系统可再次推荐场次。 |

球房开放日常天梯时，两名会员在同一台扫码并确认开局，状态记为**日常天梯对局进行中**，结束后释放球台。赛事内某一局按规则不计战力，球台仍由该赛事场次使用，正式胜负照常推进签表。

赛事用台按场次、台号和实际起止时间回查。球房娱乐用台按娱乐开台和结束记录回查。只有赛事完场记录时，只能确认该场已释放球台，接下来是否有客人用台还需核实。[娱乐开台记录的来源](<赛事待确认事项.md#公布赛程后>) · [术语](<术语.md#球房、场馆和设备>)

## 开球后的记分、结算与调整

**天梯周赛按本场让局目标推进签表。** 例如甲为 D5、乙为 D3，所用官方让局表规定甲需胜 5 局、乙需胜 3 局。即使甲已赢 4 局，乙赢下自己的第 3 局时也由乙晋级。按华彩十六球“71”打法，选手按本局让球规则清完己方目标球，再合法打进制胜球，即赢下这一局。周赛正常采用设备记分时，系统据生效赛果更新签表。官方让局与让球 · 竞赛规则 §2.1、§5.4 · 产品需求 FR-SS-44、61、63、66、69

**赛事积分按功能启用阶段办理。** 首批比赛先交付正式名次。启用赛事积分后，具有计分资格的赛事确认最终名次且无申诉，立即发分并更新榜单。有申诉时冻结本届结算，结案后按最终结果办理。[赛事积分](民间赛事认证与积分.md) · 阶段一送审稿 §9.1、§13

**开赛后的调整。** 比赛模式和单场局制锁定。比赛时间可以改，改后重新检查球台、人手、选手能否按时到场，通知受影响的人。若设备出故障，沿用原场的对阵、比分和胜局目标续赛。[现场续赛、申诉与改分](现场续赛、申诉与改分.md)
