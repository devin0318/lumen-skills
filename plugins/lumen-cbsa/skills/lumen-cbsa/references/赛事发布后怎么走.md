# 赛事发布后的办理流程

赛事开放报名后，办赛方先定正式名单，再发布签表和逐场赛程。比赛按场推进，名次按组确认，最后整届归档。

| 办理环节 | 办理事项 | 办理结果 |
|---|---|---|
| 开放报名 | 按已公布的时间、组别和条件收申请。收费时展示收款说明，办赛方在线下核款，选手的报名由经办人确认。 | 每组各有一份确认名单，候补另列。 |
| 排正式赛程 | 按确认名单和本届种子、回避办法落签。资格赛未结束时，为“资格赛出线者”留签位。结合实际可用球台、人手和选手休息安排开球时间。 | 发布签表和逐场赛程。选手可在小程序、公开站或现场大屏查到对手或晋级来源、开球时间、球台。 |
| 检录、开球 | 工作人员核对到场选手、对阵和球台，双方互认对手。身份有异议时先挂起该场，核验通过再开球。扫码取得当场档位，按本轮生效的局制确认双方各要赢几局。 | 这场比赛的实际选手、开球时间、台号、胜局目标和记分记录。 |
| 逐局记分、推进下一场 | 每打完一局，记下胜方，场比分随之更新。采用设备判分时由系统累计；采用人工记分时，由办赛方指定的工作人员录入。先达到本场胜局目标的一方获胜。 | 单败胜者自动进入下一签。循环赛按本组规则更新小组积分和排名；资格赛出线者填入对应正赛签位。 |
| 确认各组名次 | 本组和所需名次赛打完后，裁判长或赛事负责人核对结果，处理完本组复核项，按规程确认各名次及并列名次。 | 公布已确认组的名次表和签表。选手能查自己的正式成绩，办赛方可导出 PDF 或 Excel 名次表。 |
| 整届归档 | 各组结果齐全、复核项处理完，由有权人员归档。 | 本届签表、正式成绩和赛事报告。 |

**天梯周赛按本场让局目标推进签表。** 例如甲为 D5、乙为 D3，所用官方让局表规定甲需胜 5 局、乙需胜 3 局。即使甲已赢 4 局，乙赢下自己的第 3 局时也由乙晋级。按华彩十六球“71”打法，选手按本局让球规则清完己方目标球，再合法打进制胜球，即赢下这一局。周赛正常采用设备记分时，系统据生效赛果更新签表。官方让局与让球 · 竞赛规则 §2.1、§5.4 · 产品需求 FR-SS-44、61、63、66、69

**赛事积分按功能启用阶段办理。** 首批比赛先交付正式名次。启用赛事积分后，具有计分资格的赛事确认最终名次且无申诉，立即发分并更新榜单。有申诉时冻结本届结算，结案后按最终结果办理。[赛事积分](民间赛事认证与积分.md) · 阶段一送审稿 §9.1、§13

**开赛后的调整。** 比赛模式和单场局制锁定。比赛时间可以改，改后重新检查球台、人手、选手能否按时到场，通知受影响的人。若设备出故障，沿用原场的对阵、比分和胜局目标续赛。[现场续赛、申诉与改分](现场续赛、申诉与改分.md)
