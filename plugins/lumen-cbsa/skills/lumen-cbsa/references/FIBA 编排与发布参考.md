# 台球赛事可借鉴的 FIBA 编排办法

FIBA 3x3 Event Maker 的示例把 16 支队伍分成 4 个小组，每组取前 2，正好凑齐八强。它还要求组织者安排**未出线队伍的最终排名**。对台球办赛最有价值的提醒就在这里：签表能推出冠军，还不够；办赛方也得能解释其他人的名次从哪里来。[FIBA · 分组、淘汰与最终名次](https://help.fiba3x3.com/en/support/solutions/articles/35000050727-how-do-i-create-a-schedule-for-a-category-)

| 办赛事项 | Lumen 可采用的做法 |
|---|---|
| 按确认名单编排 | 组织者先进入所管理的赛事和组别。Lumen 按本届确认名单编排，候补与待定另列；资格赛出线者可先预留位置。[FIBA · 组织者入门](https://help.fiba3x3.com/en/support/solutions/articles/35000012888-how-do-i-get-started-with-the-event-maker-) |
| 小组出线和最终排名 | 先给下一阶段的签位写明晋级来源。台球可有资格赛、双败选拔、小组循环和名次赛。未出线、并列、弃权各按本届规程处理。 |
| 同台同一时段只排一场 | FIBA 先确定比赛结构，再给场次分配球场、日期、时段和预计时长。台球要换算到球台，并用本轮局制、换场间隔、工作人员和选手休息时间校验。篮球示例的比赛时长不能用于台球估时。[FIBA · 场地与时段](https://help.fiba3x3.com/en/support/solutions/articles/35000055527-scheduling-game-s-on-a-specific-court-time-and-day) |
| 工作名单和公开信息分别管理 | FIBA 让组织者决定何时公开哪些信息。Lumen 要分清办赛方手里的工作名单、选手收到的赛程、允许公开的成绩。报名资料和证件照片按各自访问权限处理。[FIBA · 对外发布](https://help.fiba3x3.com/en/support/solutions/articles/35000012895-how-do-i-control-what-gets-published-at-play-fiba3x3-com-) |

华彩十六球的开球档位、让球和让局取自本届赛事模板。设备掉线时如何接手原场、成绩什么时候生效、申诉时冻结哪些积分，都按本项目确认的办法执行。[赛程预排与计算公式](赛程预排与计算公式.md) · [现场续赛、申诉与改分](现场续赛、申诉与改分.md)
