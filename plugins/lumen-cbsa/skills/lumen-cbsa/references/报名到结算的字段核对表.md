# 报名到结算的字段核对表

同一名选手可以有三个不同的数：报名时是 D3，开球时是 D4，最后拿到 600 赛事积分。查数据前，先确认记录产生的环节。把今天的档位写回报名表，就查不出当初为什么允许他报名。

| 记录 | 字段 | 确认人与用途 |
|---|---|---|
| 第一步 · 赛事草稿 | 赛事名称、办赛单位、官方计划（选用时）、赛事模板及版本、比赛项目 | 办赛方选计划后从关联模板中选择。选模板自动带入比赛项目，民间赛事从头填写时自填项目。 |
| 第二步 · 赛事资源和打法 | 场馆、开赛时间、各组计划人数和正式名额、阶段和轮次、首轮模式与局制、名次赛、各时段球台和人手、单场用时、换场和休息间隔 | 办赛方填本届实际安排。各组共用的球台和人手按时段填一次。让局和让球按本届模板执行。 |
| 第二步 · 预排结果 | 实打场数、批数、可安排人数、预计完赛日期和时间、排不下的场次及原因 | 系统逐场排。办赛方在本步调整并重排。缺首轮规则，或可安排人数低于官方模板最低要求时，保留草稿。 |
| 第三步 · 报名规则和发布 | 报名起止、报名条件、候补上限、报名费和减免、台费承担方式、奖金说明（文本）、竞赛规程、发布或审核状态 | 办赛方沿用第二步的组别和正式名额。需审核的赛事获批后发布。 |
| 报名申请与确认名单 | 实际参赛者、代办人（如有）、组别、申请时间、提交时档位、资格核验、待定／确认／候补、确认人和时间 | 选手或获准代办人提交，办赛方确认。收费时按线下到账核对。未确认的人不占正式名额。 |
| 正式签表与赛程 | 组别、阶段、轮次、签位、种子依据、对手姓名或来源、胜负后去向、开球时间、球台、当值人员 | 编排人员用确认名单安排。资格赛还没结束时可以写“资格赛第 1 名”；不能把这个位置当轮空。 |
| 检录和开球 | 实际到场人、原场次、球台、扫码时间、双方当时的档位、本场规则版本、受让方与双方胜局目标 | 双方先互认对手。出现身份异议时挂起该场，由有权人员核验。模板规定让分时按当场扫码档位查表。开球后换台仍使用原场目标。 |
| [每局和单场结果](概念/场次、对局与局记录.md) | 场次、局次、局胜方、场比分、结果来源、现场处理人、异常或复核决定 | 指定人员与设备记录。重传同一局先核对；比赛打完才据正式胜负更新签表。 |
| 正式名次 | 组别、最终名次、并列或名次赛结果 | 处理完复核清单里所有标红项后，由裁判长或赛事负责人确认名次。 |
| 积分与更正 | 球员、本届组别的终评级别、正式名次、积分值、结算状态；更正另记原成绩版本、新版本、原因、授权、执行人和时间 | 适用积分的赛事，正式名次确认且无申诉便立即发分、更新榜单。有申诉冻结本届结算。重算后按原流水核对，只记实际变动。 |

## 用办赛实例验收

先用[天梯周赛办赛实例](<审查记录/2026-11-23 赛事主流程与需求覆盖审查.md#用天梯周赛检查办赛流程>)核对建赛、报名、检录、让分、记分和名次，再按需查下面的单项场景。

| 验收场景 | 预期结果 |
|---|---|
| 计划只关联模板 A、B，办赛方选了这项计划 | 本届从 A、B 中选。中台协新增官方计划时，至少要关联一份模板。另办民间赛可以直接选模板，或无模板时自己填项目。 |
| 官方模板只预设公开组、禁止新增，开放修改人数上限，锁定候补人数 | 办赛方可在允许范围内改公开组上限；新增组别、删除或替换预设组别、改候补人数均不能保存。 |
| 模板要求本组至少能安排 32 人，办赛方打算收 32 人，按实际球台和人手试排只能放下 24 人 | 不能完成建赛。增加时段或人手后重新试排，能安排到 32 人才通过这项检查。 |
| 两个组共用球台，下午从 4 张减为 2 张，18:00 收台 | 第二步一起重排两个组。排得下时更新预计完赛时间，排不下时列出具体组别和轮次。第三步沿用本次结果。 |
| 办赛方在第三步填写“本届比赛设有奖金”，随后修改说明文字 | 参赛人看到更新后的文字。原有试排结果和模板让分规则保持有效，发布时无需逐名次填写奖金金额。 |
| 一组只剩最后 1 个正式名额，收到两份合资格申请 | 只有经办赛方确认的人占这个名额；候补递补时再次核对余位。两份申请不会变成两个正式名额。 |
| 16 签单败，只有 10 人；另一场写着“资格赛胜者” | 首轮 6 人轮空、实际打 2 场。资格赛胜者的签位保留，等前场结果确定后再填人。 |
| 选手报名时 D3，开球时已升 D4 | 报名资格按 D3；若本轮用官方让局，让局表取 D4 和对手当场档位。无模板民间赛用 BO 平打。 |
| 开赛后从 4 号台移到 6 号台，旧设备又上传了一次第二局 | 在原场续记，已打的第二局只算一次。需要调整比赛时间时检查冲突并通知；本届各轮比赛模式和单场局制已经锁定。 |
| 刚确认最终名次时无申诉，发分后又收到申诉 | 先立即发分并更新榜单，收到申诉时冻结本届结算。维持原判解除冻结，改判则按新名次更正已发积分。上述两种结案结果都不能重复发整笔积分。 |
