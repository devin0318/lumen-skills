# 办赛角色与权限

认证球房指派小陈给天梯周赛的 3 号台记分，小陈就能记这场的比分。即便他同时是协会会员，这项指派也只对分给他的赛事和场次有效。判断一个人能做什么，先看他代表哪个单位，再看本届交给他什么工作。

| 角色 | 可办理事项 | 授权范围 |
|---|---|---|
| 中台协 | 配置、启用官方模板，指定办赛等级，发布官方计划，管理认证和正式成绩更正。 | 启用官方模板无需审核。发布一届赛事另按办赛层级审核。[赛事发布条件](<创建赛事.md#第三步　确认报名规则并发布>)赛后改分另查系统里的授权清单。 |
| 地方台协、球房及承办单位 | 按单位获准的等级、辖区或承办批复办赛。办赛方指定本届工作人员，安排报名确认、编排、检录和记分。 | 一家单位办两届比赛，要分别确认经办人获准处理哪一届。 |
| 报名、编排工作人员 | 在分配的赛事或组别核对报名、确认名单、编签、排台。 | 确认报名、生成签表、发布赛程是三个操作。能确认名单的人要有发布权限才能对外发赛程。 |
| 现场工作人员 | 在分配的场次核验到场、记录比分；设备故障时按授权续记、移台并记录交接。 | 本期由办赛方指定人员，可据此办赛。专业裁判招募、选派和履历属于后续安排。 |
| 选手、监护人 | 选手报名、查看赛程和自己的成绩、提出异议。监护人按已核实的关系代办。 | 报名和成绩记在实际参赛者名下，同时保留代办人。 |

**登录身份和授权来源。** 已有协会会员由 HY 同步资料和角色。仅在赛事系统注册的账号是参赛玩家。查办赛权限时，既看 HY 的单位角色，也看本届的工作指派。哪些单位岗位可以直接办理哪些事、谁为第一位经办人开通，见[待确认事项](赛事待确认事项.md)。

**正式成绩锁定后的改分权限。** 上级协会或中台协提交申请。另一名有改分权限的中台协管理员或指定运营人员执行或驳回。办赛方的赛事管理权限不能用于改写锁定成绩。紧急处理和留痕要求见[现场续赛、申诉与改分](现场续赛、申诉与改分.md)。
